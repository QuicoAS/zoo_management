# 🦁 Mòdul Zoo per a Odoo

## 📌 Descripció
Aquest mòdul permet la gestió de zoològics dins d'Odoo, facilitant l'emmagatzematge i gestió de dades sobre els animals, espècies i zoològics disponibles. Està dissenyat per seguir l'estructura definida al diagrama E/R i proporcionar una experiència intuïtiva per als usuaris que el gestionen.

## ⚙️ Característiques
- Gestió d'animals i espècies.
- Creació i administració de zoològics.
- Vistes **tree**, **form** i **kanban** per facilitar la navegació.
- Menús i accions adaptades per a una millor usabilitat.
- Suport per a la visualització i gestió de dades en PostgreSQL.

## 🏗 Instal·lació
1. Copia la carpeta `zoo_module/` a la teva instància d'Odoo dins del directori `addons/`.
2. Reinicia el servidor d'Odoo.
3. Activa el mode desenvolupador a Odoo.
4. Instal·la el mòdul des del menú de **Aplicacions**.

## 📝 Configuració i ús
1. Accedeix a **Zoo Management** des del menú principal.
2. Afegeix nous zoològics, espècies i animals amb les vistes form.
3. Utilitza la vista **tree** per visualitzar els registres.
4. Explora la vista **kanban** per a una representació més visual.

## 📌 Desenvolupament

- Instal·lació, proves i vista kanban (`activitat_4`).
